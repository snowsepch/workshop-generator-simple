# Apple Shop 小教室專案 · 簡易實戰版

門市小教室顧客簡報生成器（簡易實戰版）。純前端單檔，所有運算在瀏覽器本機執行，不外傳任何資料。

線上直接使用網址：https://snowsepch.github.io/workshop-generator-simple/

## 核心實戰特色

- **精緻 8 頁實戰架構**：封面 → 課程重點 → 核心亮點與相容性需求 → 四大生活應用情境 → 一起動手做（具體路徑） → 示範效果對比與避坑 → 實用配件推薦與門市保證 → 帶回家一句話與實踐。
- **本頁講師備忘錄即時對照**：切換投影片零時差同步顯示轉場話術、互動提問句與講師防呆動作。
- **課前 3 分鐘準備清單**：內建 60 分鐘配速表、器材環境必檢表與現場突發三大救援保命題。
- **主題庫星等推薦**：⭐ 新手首選（★☆☆）、⏱ 節奏好掌控（★★☆）、💡 專業進階（★★★），如 Menu 點菜般清晰。
- **具體操作路徑與對比**：擺脫通用抽象文字，帶入真實設定路徑與「Before vs After」效果對比。

## 內容維護（給夥伴）

- 主題資料都在 `index.html` 的 `TOPICS` 陣列，每個硬體主題上方有註解，寫明來源網址與核對日期。
- 事實一律以 Apple 台灣官網（apple.com/tw）為準；官網沒寫的不寫，售價不放進主題。
- 會過期的內容（開賣日、Beta 功能開放語言與地區）已在註解標出，開賣或開放後請改寫。
